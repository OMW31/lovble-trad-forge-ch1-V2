# PRD_CH1_WORLD_CLASS

## Produit
TradForge Academy — Chapitre 1: Analyse Fondamentale

## Vision
Transformer le chapitre actuel en expérience immersive institutionnelle, sans casser l’architecture pédagogique existante.

## Règles absolues
- Ne pas reconstruire from scratch.
- Ne pas supprimer le contenu pédagogique validé.
- Ne pas créer de nouvelles sections.
- Déplacer, enrichir, densifier, illustrer, animer.
- Maintenir un registre anti-régression vivant.

## Objectifs produit
1. Hausser radicalement le niveau perçu du chapitre.
2. Introduire une vraie persistance utilisateur.
3. Permettre la reprise exacte où l’utilisateur s’est arrêté.
4. Préparer l’industrialisation séquentielle de tous les blocs du roadmap.
5. Encadrer l’implémentation par une documentation opérable.

## Résultats attendus
- Hero V2 avec Mission Briefing et Macro Radar.
- Redistribution des scénarios dans les sections 1.1 → 1.5.
- Macro dashboard premium et widgets d’analyse.
- Système d’évaluation modal 3 niveaux.
- Profils, progression, reprise exacte et tentatives persistées.
- Breadcrumb mobile inférieur.
- Motion bidirectionnel et interaction system premium.

## Utilisateur cible
Apprenant sérieux orienté marchés / macro / finance, qui veut une expérience dense, premium, proche d’un environnement institutionnel.
