# CH1_WIDGET_SYSTEM

## Mission
Passer d’une collection de widgets à un système cohérent de lecture, manipulation et décision.

## Règles
- chaque widget doit avoir un objectif pédagogique explicite
- chaque widget doit être relié à un driver fondamental réel
- chaque widget doit rendre une variable lisible et manipulable

## Statut actuel
Couverture CH1 V2 complète pour le périmètre planifié. Les widgets forment désormais un système macro → micro → valorisation → scénario → évaluation.
