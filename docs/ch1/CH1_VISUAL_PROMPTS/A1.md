# A1 — Écosystème macroéconomique

## Statut
- Version : v2
- Date : 2026-08-18
- id runtime : `a1` (IMMUABLE, référencé par la banque de questions Partie B)
- Chemin : `public/academy/ch1/visuals/a1.webp`

## Intention pédagogique
Poser en une image la totalité du système macro que le chapitre va démonter : croissance, inflation, emploi, balance commerciale, taux directeurs et flux de capitaux comme rouages d'une même machine. L'élève doit comprendre, avant toute lecture, que ces variables ne sont jamais isolées mais interconnectées. Ce visuel ouvre le triptyque a1/a2/a3 qui structure la lecture macro du chapitre.

## Emplacement runtime
- Leçon : 1.2 — Comprendre la macroéconomie
- Sous-section : `macro-concept`
- Composant : `VisualExplainer`
- Mode : les deux (cours + évaluation Partie B)

## Contraintes de cadrage
- Ratio strict **16:9**, composition pensée pour un recadrage sûr en 21:9 et 4:3.
- Zone de sécurité centrale : aucun élément narratif critique en dehors du cadre 84 % central (marge de sécurité de 8 % sur chaque bord).
- Lisibilité garantie de **390px** (mobile) à **2560px** (desktop 2K) : formes larges, contrastes francs, pas de détail fin illisible en dessous de 800px de large.
- Aucun élément critique dans les **8 % de bord** (haut, bas, gauche, droite) — ces zones peuvent être recouvertes par des masks/gradients d'intégration (`VisualLayer`).
- Le logo TradForge (si présent en haut à gauche) reste toujours dans l'espace de sécurité et ne colle jamais au bord.

**Règle cardinale** : zéro texte pédagogique incrusté dans le bitmap. Seul le logo TradForge peut porter de la typographie. Toute donnée pédagogique (titres, légendes, callouts, chiffres) vit exclusivement dans la couche native HTML/SVG (`VisualExplainer` / `VisualLayer`).
