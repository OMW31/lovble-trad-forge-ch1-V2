# CH1_INTERACTION_SYSTEM

## Philosophie
L’utilisateur doit manipuler, arbitrer, comparer, décider.

## Interactions obligatoires
- filtre
- slider
- sélection d’hypothèse
- drill-down
- switch de scénario
- validation / feedback immédiat
- comparaison de pairs
- lecture de surprise vs consensus

## Standards
- toute interaction doit produire un changement perceptible
- pas de contrôle décoratif sans conséquence visible
- feedback d’erreur / succès clair
- surfaces interactives cohérentes entre elles

## Priorités de build
1. Progression persistée
2. Widgets macro à forte valeur
3. Evaluation modal
4. Scenario builder
5. Motion polish
